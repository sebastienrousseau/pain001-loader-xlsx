# pain001-loader-xlsx v0.0.86

## Highlights ⭐️

* **In lockstep with pain001 0.0.86**: the loader reads workbooks and emits records exactly as in 0.0.85.
* **README Quick Start runs in CI**: `tests/test_readme.py` builds a workbook from core's template rows, lists the loaders and generates XML, so a CLI or entry-point change fails CI instead of a reader's terminal.
* **Contributor tooling**: a code of conduct, issue forms, a pull request template, AGENTS.md, pinned pre-commit hooks, a devcontainer and markdownlint and codespell jobs.
* **One developer guide**: DEVELOPMENT.md covers the toolchain, the local command for every CI job and the release model, and the manual checks its links and author line on every page.

## Details

pyproject.toml, `__version__`, CITATION.cff, the README and the SECURITY.md and SUPPORT.md tables move to 0.0.86 together.
