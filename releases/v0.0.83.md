# pain001-loader-xlsx v0.0.83

## Highlights ⭐️

* **In lockstep with pain001 0.0.83**: this package requires `pain001 >= 0.0.83, < 1`. The core can now verify XML signatures against the signer's certificate with `pain001 verify-signature`.
* **Nothing in the loader changed**: this release moves only the version and the `pain001` floor, and the XML the core writes from workbook rows is the same as with 0.0.82. Upgrade it together with the core.

## Details

* Every hash-pinned requirements file that carries `pain001` now pins 0.0.83; only `pain001` moved.
