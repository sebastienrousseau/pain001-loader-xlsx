# pain001-loader-xlsx v0.0.69

No loader changes: `XlsxLoader` behaves exactly as it did in 0.0.68.
This release keeps the package on the suite's version number.

## Why the number moved

The `pain001` suite ships **one version number across all five
packages** by policy. The core released 0.0.69, its third
example-corpus release: the tier 2 and 3 market packs, the CSV pipeline
extension and the pain.001 twin foundation. The four members follow it
so that a `pip install` of any one of them names the same suite.

## Upgrade

```sh
pip install --upgrade pain001-loader-xlsx
```

Nothing to migrate.
