# pain001-loader-xlsx v0.0.66

No loader changes: `XlsxLoader` behaves exactly as it did in 0.0.65.
This release keeps the package on the suite's version number.

## Why the number moved

The `pain001` suite ships **one version number across all five
packages** by policy. The core released 0.0.66 with cross-record
duplicate detection, the `/api/v1/ui` dashboard, GPG flags and
OpenTelemetry spans; the four members follow it so that a `pip install`
of any one of them names the same suite.

## Upgrade

```sh
pip install --upgrade pain001-loader-xlsx
```

Nothing to migrate.
