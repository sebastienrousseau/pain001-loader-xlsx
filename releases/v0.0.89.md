# pain001-loader-xlsx v0.0.89

## Highlights ⭐️

* **In lockstep with pain001 0.0.89**: the loader reads workbooks and emits records exactly as in 0.0.88. It now requires pain001 0.0.89.
* **The docs set compiles again**: `make pip-compile` resolves the documentation requirements at Python 3.11.5, the oldest version soupsieve 4 supports, and stops on the first failure instead of leaving a stale lock file behind.
* **complexipy 9 in the complexity gate**: the ratchet's compare step is split in two so it stays under the cognitive ceiling of 15 that complexipy 9 measures, with the same report.
* **Dependabot updates folded in**: ruff 0.17.5, filelock 4.2.10, myst-parser 5.2.0, mdit-py-plugins 0.7.0 and complexipy 9.0.0 in the hash-pinned development sets. The published package's own dependencies are unchanged.

## Details

pyproject.toml, `__version__`, CITATION.cff, the README and the SECURITY.md and SUPPORT.md tables move to 0.0.89 together.
