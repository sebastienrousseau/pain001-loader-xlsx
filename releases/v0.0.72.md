# pain001-loader-xlsx v0.0.72

This release aligns `pain001-loader-xlsx` with `pain001` core v0.0.72.

## What's Changed

- **Security Hardening**: Shield cells from CSV and Excel formula injection by disarming leading formula triggers (`=`, `+`, `-`, `@`, `\t`, `\r`) in string fields during workbook loading.
- **Supply Chain Security**: Add SLSA Level 3 provenance attestations to release artifacts.
- **Ecosystem Coordination**: Synchronize version 0.0.72 across the pain001 ecosystem while preserving the structural plugin contract (`pain001 >= 0.0.56, < 1`).

## Upgrade

```sh
pip install --upgrade pain001-loader-xlsx
```

Nothing to migrate.
