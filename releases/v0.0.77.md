# pain001-loader-xlsx v0.0.77

* **In lockstep with pain001 0.0.77**: the family ships one version again, and this package requires `pain001 >= 0.0.77, < 1`. The loader is unchanged.

* **0.0.76 folded in**: 0.0.76 was prepared but never tagged or published, so its changes ship in this release.
