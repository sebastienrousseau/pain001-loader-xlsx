# pain001-loader-xlsx v0.0.81

## Highlights ⭐️

* **In lockstep with pain001 0.0.81**: this package requires `pain001 >= 0.0.81, < 1`. In 0.0.81 the core checks every IBAN and BIC and refuses rows that mix payment batches, including rows read from a workbook.
* **Nothing in the loader changed**: this release moves only the version and the `pain001` floor. Upgrade it together with the core.

## Details

* Every hash-pinned requirements file that carries `pain001` now pins 0.0.81; no other dependency moved.
