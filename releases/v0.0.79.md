# pain001-loader-xlsx v0.0.79

## Highlights ⭐️

* **In lockstep with pain001 0.0.79**: this package requires `pain001 >= 0.0.79, < 1`. The loader is unchanged.
* **Release page in the suite's shape**: the release workflow now writes the title, Highlights, What's Changed and Checksums itself with `scripts/release_notes.py`, so the page no longer needs rewriting by hand.
* **Release notes checked on every pull request**: `tests/test_release_notes.py` fails a pull request whose CHANGELOG dates a version without a matching `releases/vX.Y.Z.md` of two to four highlights.

## Details

* Every hash-pinned requirements file that carries `pain001` now pins 0.0.79; no other dependency moved.
* `scripts/release_notes.py` and `tests/test_release_notes.py` are vendored byte-identical from `pain001`.
