# pain001-loader-xlsx v0.0.74

## Highlights ⭐️

* **Text cells carry what Excel displays**: OOXML stores a carriage return as `_x000D_`, and openpyxl hands that back as text, so a multi-line cell reached the payment as escape characters. The escapes are now decoded, so the XML matches the CSV export of the same sheet, and a cell holding a character XML cannot carry is refused with its column, row and code point.
* **Cells starting with `=`, `+`, `-` or `@` stay as written**: 0.0.72 put a single quote in front of them, so `-5` reached the XML as `'-5`. Like the pain001 0.0.74 CSV loader, this loader now keeps the raw value; the generated XML changes for such cells.
* **In lockstep with pain001 0.0.74**: this release requires `pain001 >= 0.0.74`. The family skips 0.0.73, which only pain001-mcp published. The scheduled Suite Consistency check now compares the tree with this package's own PyPI release, not the core's.
* **Supply chain to the family standard**: every CI install is hash-pinned and audited with `pip-audit`, every function is held to the complexity ceilings, text cells are fuzzed with Atheris, and release titles read `pain001-loader-xlsx <version>`.
