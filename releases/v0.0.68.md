# pain001-loader-xlsx v0.0.68

No loader changes: `XlsxLoader` behaves exactly as it did in 0.0.67.
This release keeps the package on the suite's version number.

## Why the number moved

The `pain001` suite ships **one version number across all five
packages** by policy. The core released 0.0.68, its second
example-corpus release: the tier-1 market packs, coverage files named
by recipe and focus, and the tooling to apply a bank's own guideline
privately. The four members follow it so that a `pip install` of any
one of them names the same suite.

## Upgrade

```sh
pip install --upgrade pain001-loader-xlsx
```

Nothing to migrate.
