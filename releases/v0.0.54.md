# pain001-loader-xlsx Release v0.0.54

**Release Date:** 2026-07-18
**Tag:** v0.0.54
**Python:** 3.10+
**Status:** Stable

## Executive Summary

A dependency release. It pins `pain001 >= 0.0.56` — the first PyPI release that
actually ships the `pain001.plugins` substrate this loader discovers through
(the entry-point group `pain001.loaders`). pain001 0.0.56 also carries the
0.0.55 path-injection hardening, so this release inherits that fix transitively.
No loader behaviour changes.

## What's in v0.0.54 at a glance

- **`pain001 >= 0.0.56, < 1`** (was `>= 0.0.54`). 0.0.56 is the release that
  merged the plugin substrate + GPG loader + OpenTelemetry surface onto the
  0.0.55 security fix.
- **CI simplified**: the temporary "install pain001 from its `feat/v0.0.54`
  branch if not yet on PyPI" fallback is removed — a plain
  `pip install "pain001>=0.0.56,<1"` now suffices.
