# pain001-loader-xlsx v0.0.82

## Highlights ⭐️

* **In lockstep with pain001 0.0.82**: this package requires `pain001 >= 0.0.82, < 1`. For pain.001.001.04 to .08 the core now writes a valid IBAN column as `<IBAN>` and a non-empty `service_level_code` column as `PmtTpInf/SvcLvl/Cd`, including for rows read from a workbook.
* **Nothing in the loader changed**: this release moves only the version and the `pain001` floor. Upgrade it together with the core.

## Details

* Every hash-pinned requirements file that carries `pain001` now pins 0.0.82.
* Rows whose `service_level_code` values differ are now refused for .04 to .08, as they already were for .03 and .09 to .13: put each service level in its own workbook or sheet.
* The development tools ruff and filelock moved to their latest patch releases.
