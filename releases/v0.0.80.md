# pain001-loader-xlsx v0.0.80

## Highlights ⭐️

* **In lockstep with pain001 0.0.80**: this package requires `pain001 >= 0.0.80, < 1`. pain001 0.0.80 is a security release of the core's REST API ([GHSA-vv3x-jpvc-w468](https://github.com/sebastienrousseau/pain001/security/advisories/GHSA-vv3x-jpvc-w468)).
* **Nothing in the loader changed**: this release moves only the version and the `pain001` floor. Upgrade it together with the core.
